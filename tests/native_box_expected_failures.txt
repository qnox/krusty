evaluate/intrinsicConst/enumNameWithInit.kt	`EnumClass.OK.name` under +IntrinsicConstEvaluation is meant to fold at compile time, so the enum's `init` never runs; krusty evaluates it at run time and the `init` sets "Fail" — krusty's JVM backend prints the identical "Fail", so the folding is the frontend's to do
